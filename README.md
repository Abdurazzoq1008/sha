# Melfis Flowers

Melfis Flowers — Samarqand gul do'koni uchun React, Vite va Tailwind CSS asosida yaratilgan onlayn vitrina.

## Ishga tushirish

Node.js 20.19+ yoki 22.12+ talab qilinadi.

```bash
npm install
npm run dev
```

## Tekshirish va production build

```bash
npm run build
npm run preview
```

## Vercel'ga joylash

GitHub repozitoriysini Vercel'da import qiling. Framework preset `Vite`, build command `npm run build`, output directory `dist`. `main` branch'ga yuborilgan o'zgarishlar avtomatik deploy bo'ladi.
